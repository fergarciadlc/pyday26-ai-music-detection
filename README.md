# Detección de IA en música · PyDay México 2026

Companion website and material for the talk **"Detección de IA en música"** by Fernando
Garcia de la Cruz at PyDay México 2026.

🌐 **Site:** https://fergarciadlc.github.io/pyday26-ai-music-detection
📄 **Slides:** [`docs/assets/slides/pyday26mx-ai-music-detection.pdf`](docs/assets/slides/pyday26mx-ai-music-detection.pdf)

The site (in Spanish) follows the talk's agenda: the opening "¿Cuál es IA?" experiment, how
music is generated with a neural codec (EnCodec latents you can listen to), how it is detected
(spectrograms and a binary CNN in PyTorch), the decoder's *fakeprints* in an interactive A/B
panel, and the papers and code referenced in the talk.

There are two versions while we decide:

- **v2, `web/`** (deployed): a minimal single static page, no build step.
- **v1, `docs/` + `mkdocs.yml`**: a longer, multi-page MkDocs Material site with every
  example included step by step.

Both use the same audio, images and scripts in `docs/assets/`; `web/assets` is a symlink to it.

## Layout

```
web/                   v2: index.html + static/ (CSS, CNN diagram); assets -> ../docs/assets
docs/                  v1 MkDocs pages, and the shared assets
  assets/brand/        PyDay México 2026 artwork (from the speakers' template)
  assets/examples/     generated by examples/*.py
  assets/fakeprints/   generated by scripts/build_fakeprints.py
  assets/quiz/         generated by scripts/prepare_quiz_audio.py
  assets/js, css       quiz and fakeprints panel (vanilla JS, no dependencies)
  atlas.html           Audio Atlas (standalone page)
examples/              the tutorial code (runnable scripts)
audio/                 source recordings (guitar, Suno clips, YouTube links)
scripts/               Python scripts that precompute the site's audio, data and diagram
```

## Examples

Each example is a plain script (with `# %%` cells, so it also opens as a notebook in VS Code
or Jupyter).

```bash
uv run --group audio examples/01_espectrogramas.py
uv run --group audio examples/02_codec_latentes.py
uv run --group audio examples/03_detector_pytorch.py   # downloads the MUSDB18 7 s sample (~140 MB) to ~/MUSDB18
```

## Run locally

```bash
python3 -m http.server -d web 8000   # v2 → http://127.0.0.1:8000
uv run mkdocs serve                  # v1 → http://127.0.0.1:8000 (requires uv)
```

Regenerate the assets (downloads EnCodec from Hugging Face; needs `ffmpeg`):

```bash
uv run --group audio scripts/build_fakeprints.py audio/guitar.mp3
uv run scripts/prepare_quiz_audio.py
uv run scripts/build_cnn_diagram.py ../ismir26-how-much-ai/assets/diagrams/architecture.svg web/static/cnn.svg
```

## Deploy

`.github/workflows/pages.yml` publishes `web/` to GitHub Pages on every push to `main`
(set *Settings → Pages → Source* to **GitHub Actions**).
