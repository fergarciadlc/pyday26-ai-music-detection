# ¿Suena a IA? · PyDay México 2026

Companion website and material for the talk **"¿Suena a IA? Detección de música generada por
inteligencia artificial"** by Fernando García de la Cruz at PyDay México 2026.

🌐 **Site:** https://fergarciadlc.github.io/pyday26-ai-music-detection
📄 **Slides:** [`docs/assets/slides/pyday26mx-ai-music-detection.pdf`](docs/assets/slides/pyday26mx-ai-music-detection.pdf)

The site (in Spanish) has:

- **¿Cuál es IA?**: the six clips from the opening quiz, with their answers.
- **Fakeprints**: a guitar recording before and after the EnCodec neural codec. You can
  listen to both in sync (A/B) and see the decoder's fingerprint, a comb of spectral peaks
  every 600 Hz.
- **Recursos**: papers, data and code referenced in the talk, plus the *Audio Atlas* of
  generative audio models.

## Layout

```
docs/                  MkDocs site (Markdown pages + assets)
  assets/fakeprints/   generated by scripts/build_fakeprints.py
  assets/quiz/         generated by scripts/prepare_quiz_audio.py
  assets/js, css       quiz and fakeprints panel (vanilla JS, no dependencies)
  atlas.html           Audio Atlas (standalone page)
audio/                 source recordings (guitar, Suno clips, YouTube links)
scripts/               Python scripts that precompute the site's audio and data
```

## Run locally

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv run mkdocs serve          # http://127.0.0.1:8000
```

Regenerate the assets (downloads EnCodec from Hugging Face; needs `ffmpeg`):

```bash
uv run --group audio scripts/build_fakeprints.py audio/guitar.mp3
uv run scripts/prepare_quiz_audio.py
```

## Deploy

`.github/workflows/pages.yml` builds the site and publishes it to GitHub Pages on every
push to `main` (set *Settings → Pages → Source* to **GitHub Actions**).
